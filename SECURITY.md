# Security policy

Report suspected vulnerabilities privately to security@<your-domain> (replace before publishing) or through GitHub private vulnerability reporting for this repository. Please do not open public issues for security problems.

What to expect (targets, to be confirmed in `docs/security/VULNERABILITY-HANDLING.md`): acknowledgement within 3 business days, triage within 7 days, fixes for critical issues within 14 days. We will credit reporters who want credit and will not pursue good-faith research that follows this policy.

Supported versions: the latest release and the one before it.
