# ADR-015: Open Evidence Statement specification

- **Status:** Accepted (23 October 2026, founder decision D2; design-partner review before publication)
- **Context:** Customers, auditors and insurers need a portable, verifiable format for causal value claims. A proprietary format limits adoption and weakens the independence story.
- **Decision:** Define and publish a versioned schema for Evidence Statements (estimate, interval, grade, assumptions, plan reference, estimator digest, input references). Realize it as a SCITT profile (ADR-018). Keep the reference implementation, data asset and connectors proprietary.
- **Consequences:** Possible standard-setting position and lower switching fear; others may implement it; requires design-partner review before publication.
