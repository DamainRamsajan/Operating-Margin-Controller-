# ADR-022: Assurance-ecosystem alignment and partner channel

- **Status:** Accepted (26 October 2026, founder decision D7)
- **Context:** SOC 2, ISO/IEC 42001, CSA STAR for AI and AIUC-1 define how buyers, auditors and insurers talk about AI trust; the AICPA and AIUC announced a joint certification on 19 October 2026 and underwriting converges on the same frameworks [S31][S32][S33][V]. These frameworks certify controls and agent behavior; they do not measure outcome truth, change safety or action authority.
- **Decision:** Map each statement type to the controls it can support (AIUC-1, ISO/IEC 42001, SOC 2, NIST AI RMF), provide a partner interface and public verifier, and run a partner program for CPA firms, certifiers and insurers. OMC claims support for a control, never certification, and issues no certificates.
- **Consequences:** Channel and credibility; dependence on partners' frameworks; mappings need validation (spike S-h); partner arrangements must not depend on findings (ADR-026).
