# ADR-039: First release scope

- **Status:** Accepted (29 October 2026, founder decisions D14 and D15)
- **Context:** The audit products must prove value before any control authority is requested; the UX research favors designing for a few personas first.
- **Decision:** The first release is read-only: it shows verdicts, evidence and review queues and writes only human review labels. There is no actuation console. The first personas designed and tested are the support operations lead and the finance controller, then the expert reviewer.
- **Consequences:** Smaller security surface and a faster route to design partners; actuation, bake-off and approvals screens wait for evidence that customers want them; local-only access with no login until the tenant deployment work.
