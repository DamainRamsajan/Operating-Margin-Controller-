# ADR-034: Verdict-first language and evidence chips

- **Status:** Proposed
- **Context:** Error bars and p-values are widely misread; frequency framing and dot-style displays improve understanding [S43].
- **Decision:** Every analysis opens with promote, hold or reject (or a measured rate) in one sentence, uses counts per 1,000 cases with the denominator, shows the range and tolerance together, and carries an evidence-grade chip with text. Exact bounds sit one level down. Comprehension is tested before release.
