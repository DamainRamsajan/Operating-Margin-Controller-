# ADR-025: Public verifier, schema and test vectors

- **Status:** Accepted (26 October 2026, founder decision D7)
- **Context:** A claim is only as credible as the ability of others to check it; certifiers and insurers will not rely on a closed checker.
- **Decision:** Release the verifier CLI, the statement schema and a set of test vectors under a permissive open-source licence; keep the engine, connectors and data asset proprietary.
- **Consequences:** Third-party verification and reference-format potential; others can implement the format; licence choice is decision D8.
