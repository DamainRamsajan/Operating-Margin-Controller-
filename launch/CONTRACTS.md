# Contracts

Use Common Paper's standard agreements (free to use and modify under CC BY 4.0; the free account allows a small number of agreements a month with e-signature; check current limits) [V].

| Order | Document | When |
|---|---|---|
| 1 | Mutual NDA | Only if the partner asks before sharing details |
| 2 | **Design Partner Agreement** | First two partners (free pilot, feedback, anonymized publication rights) |
| 3 | **Pilot Agreement** | Paid pilots (time-limited, fixed fee, opt-out terms) |
| 4 | Data Processing Agreement | Only if any personal data is processed; the plan is pseudonymized decisions only, so keep the data out of scope if possible |
| 5 | Cloud Service Agreement and Order Form | Subscriptions after the pilot |

Fill in: parties, fees, term, data description (decisions, labels, pseudonymized ids), publication rights, and the no-contingent-fee statement. Have a startup lawyer review liability, IP and data terms once before the first signature.
